What I Built
I added a search and filter feature to the menu page of Vinchenzo's Pizza Shoppe, a fictional spicy pizza restaurant site. Users can type into a search bar to find items by name, description, or toppings, and also click category filter buttons (All, Signature, Classic, Sides & Drinks) to narrow down the menu. Both filters work together simultaneously, so you can select a category and search within it at the same time.
How Micro-Iteration Felt
Honestly, it felt frustrating and tedious. When you're using AI specifically to speed up coding, being forced to slow down and do one small step at a time feels counterproductive. That said, I can see the argument for it on more complex projects where bugs compound on each other. For something like this, it mostly just felt like artificial restraint.
What Self-Review Caught
Copilot caught several real issues during self-review. On Step 1 it flagged accessibility problems like missing type="button" on filter buttons, the need for aria-pressed="true" on the active button, and the search icon emoji needing aria-hidden="true" for screen readers. On Step 2 it caught a null pointer exception risk where calling .textContent on a missing element would crash the script, redundant DOM queries where searchInput was being queried twice instead of cached once, and inefficient selectors that searched the whole DOM subtree unnecessarily. It also predicted the Step 5 conflict before we even got there, noting that search and category filtering would interfere without unified logic.
Tool Impressions
Copilot Agent was straightforward and to the point. It didn't pad responses with unnecessary explanation, which made the iteration cycles feel faster. The agent mode integration directly in VS Code also meant I wasn't context-switching between windows constantly.
Self-Review Patterns
Copilot consistently caught accessibility issues and null safety problems across multiple steps. Edge cases around empty states (empty search, no results) also came up repeatedly. It was good at predicting future conflicts, like flagging the search vs. category filter collision before Step 4 even started. It didn't miss anything major that I caught myself, though some of its suggestions were more best-practice than strictly necessary.
Copilot Agent vs. Claude Code CLI
Claude Code CLI feels more powerful for larger, multi-file tasks where you want the AI to have full project context and make sweeping changes. Copilot Agent inside VS Code is better for focused, contained work where you want to stay in one environment without switching tools. CLI gives more control; Copilot Agent feels more integrated into the normal coding workflow.
When to Use Micro-Iteration
Micro-iteration makes the most sense for complex features where bugs can stack up and become hard to untangle at the end. Debugging one step at a time is much easier than dissecting a large block of generated code all at once. For simple, well-scoped features like this one, it adds more overhead than it saves.
